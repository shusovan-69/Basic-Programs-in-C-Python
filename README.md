# Basic Programs in C & Python

A collection of beginner-friendly programming programs created while learning the fundamentals of **C and Python**.

This repository contains small programs and mini-projects focused on logic building, problem-solving, conditions, loops, functions, randomization, and basic user interaction.



## 🛠️ Technologies

* **Python 3**
* Basic programming concepts
* Conditional statements
* Loops
* Lists and variables
* User input
* Functions
* Random module
* Basic problem solving

## 🎯 Purpose

The main purpose of this repository is to:

* Practice programming fundamentals
* Improve logical thinking
* Build small projects while learning
* Keep track of programming practice
* Create a foundation for learning **DSA, Python, and AI/ML**

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/shusovan-69/Basic-Programs-in-C-Python.git
```

### 2. Open the project

```bash
cd Basic-Programs-in-C-Python
```

### 3. Run a Python program

```bash
python filename.py
```

For example:

```bash
python game.py
```
